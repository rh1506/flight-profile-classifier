# flight-profile-classifier
Automated classification of drone imagery into 8 flight profiles for infrastructure inspection. Transfer learning model trained on 28,000+ real drone photos.
**28,853 real drone photographs** from 45 infrastructure inspections:

| Profile | Photos | Accuracy |
|---------|--------|----------|
| Center Out | 888 | 100.0% |
| Uplook | 2,804 | 100.0% |
| Center In | 3,000 | 99.5% |
| Tower Flight | 15,051 | 92.5% |
| Cable Run | 999 | 80.6% |
| Compound Flight | 3,240 | 83.2% |
| Overall | 90 | 68.9% |
| Downlook | 2,781 | 67.9% |

**Overall Accuracy: 90.3%** — generalizes well to unseen tower inspections.
